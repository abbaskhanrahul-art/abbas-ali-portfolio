# MD. Abbas Ali — Portfolio Starter

A responsive static portfolio website. No coding or build step is required to deploy.

## Publish with GitHub + Vercel
1. Create/sign in to GitHub and make a new public repository named `abbas-ali-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Sign in at https://vercel.com/ using GitHub.
4. Choose **Add New → Project**, import the repository and deploy.
5. If asked for a framework, choose **Other**. No build command or output directory is needed for this static site.
